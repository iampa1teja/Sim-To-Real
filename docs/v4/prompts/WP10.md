# WP10 — the cube tasks: pick_place_cube additions, stack_two_cubes, pick_place_color_cube (Codex prompt)

## Goal

Make the three cube tasks generate datasets with the scripted expert: extend the existing `pick_place_cube` (keeping teleop and eval exactly as they are), and add `stack_two_cubes` and the precise multi-colour task `pick_place_color_cube` (2 cm cubes into a 4 cm box, 2–6 cubes, the instruction names the colour, the box position is randomised, colour `purple` and count 4 held out).

## Decisions (pinned by the tests)

- `pick_place_cube` keeps `PickPlaceTask` and its contact-sensor signals (`grasped`, `lifted`, `placed`, `success` come from `state.signals`; FakeEnv synthesises them). `stages` stay `("reached", "grasped", "lifted", "over_box", "placed", "success")`; `[task.stages].order` repeats them (the world perturber reads the order from the table) with **no** `hold_until`. `[task.failures]` reproduces the six names in `StageTrace.finish` order. Variants: the existing three plus `generate = "env_cfg:apply_generate"`. Instruction unchanged; no instruction template.
- `PickPlaceTask.observe`: `reached` = `‖tcp − cube‖ ≤ 0.03` with `tcp = state.tcp` when it is set, else `state.ee` (eval passes no TCP, so eval is unchanged). `_over_box` uses private copies of `rotation_matrix` / `footprint` (or a new Isaac-free `tasks/pick_place_cube/geometry.py` that `eval.py` imports), because importing `eval.py` reads the default arm at import time.
- Perturbations that need a stage whose check implies holding (`object_drop`) cannot be used with `PickPlaceTask` (its stages are signals, not checks); use the types in the appendix. A recovery needs a regression the expert can detect; with no `hold_until`, only `grasp_offset` works for `pick_place_cube`.
- `stack_two_cubes`: objects `red_cube` and `blue_cube` (2 cm, 8 g), roles `target = "red_cube"`, `base = "blue_cube"`, instruction "Stack the red cube on the blue cube"; `stacked` is `all(object_on_object(@target on @base), released)`. Pitfalls found while proving the tests: `over_base` must not be in `hold_until` (the "above the base" check stops holding while the cube is lowered), and the `raised` lift threshold must be ≤ 0.01 m (a cube resting on the base is only 2 cm above its start, so a 2 cm threshold makes `lifted` drop during the placement and the expert re-enters).
- `pick_place_color_cube`: the §4.6 colour example with real regions: palette exactly {red, green, blue, yellow, orange, purple, pink} (the fx7_color values), `[task.holdout]` colours `["purple"]` and counts `[4]`, `count = [2, 6]`, box `small_box` with `size_outer = [0.05, 0.05, 0.035]`, `inner_half_size = [0.02, 0.02]`, `floor_z = 0.002`, `origin = "bottom"`, randomised position and yaw, failure `wrong_object_placed` first.
- `usd/Small-Box-Physics.usda`: starts with `#usda 1.0`, declares `defaultPrim`, and the default prim has `float3[] extent = [(-0.025, -0.025, 0), (0.025, 0.025, 0.035)]` (bottom origin). Floor 2 mm thick, four walls; collision as convex pieces (one per wall and the floor) so Newton handles it; rigid, kinematic or fixed as the generic env config expects.
- `configs/generate/cube_tasks.yaml`: valid for `load_generate_config`; quotas are owner decisions (proposal: success 4000 / failure 1000 / recovery 1000 per task).

### `tasks/pick_place_cube/task.toml` additions

`[task.variants]` gains `generate = "env_cfg:apply_generate"`; append:

```toml
[task.roles]
target = "blue_cube"
container = "white_box"

[task.start]
table_z_m = 0.0
min_separation_m = 0.035
clearance_m = 0.01
reachable = ["@target", "@container"]

[task.start.place.white_box.region]
xy_min = [-0.252, 0.0005]
xy_max = [-0.242, 0.0105]

[task.start.place.blue_cube]
yaw_deg = [0.0, 90.0]

[task.start.place.blue_cube.region]
xy_min = [-0.25, -0.40]
xy_max = [0.25, -0.18]

[task.stages]
order = ["reached", "grasped", "lifted", "over_box", "placed", "success"]

[task.failures]
rules = [{ name = "placed_not_confirmed", if = ["placed"] }, { name = "never_reached", unless = ["reached"] }, { name = "missed_grasp", unless = ["grasped"] }, { name = "timeout_holding", if = ["holding"] }, { name = "dropped_before_box", unless = ["over_box"] }, { name = "dropped_outside" }]

[task.expert]
max_steps = 600
steps = [{ skill = "move_joint", q = "home" }, { skill = "set_gripper", gap_m = "open" }, { skill = "approach", target = "@target", offset_m = [0, 0, 0.06], stage = "reached" }, { skill = "grasp", target = "@target", stage = "grasped" }, { skill = "lift", height_m = 0.08, stage = "lifted" }, { skill = "transport", target = "@container", height_m = 0.06, stage = "over_box" }, { skill = "place", target = "@container" }, { skill = "release", stage = "placed" }, { skill = "retreat", dz_m = 0.08, stage = "success" }]

[task.perturbations]
failure = [{ type = "grasp_offset", weight = 2, xy_m = [0.008, 0.02] }, { type = "early_release", stages = ["lifted"], delay_steps = [5, 40] }, { type = "place_offset", xy_m = [0.08, 0.12] }]
recovery = [{ type = "grasp_offset", xy_m = [0.008, 0.02] }]
```

### `tasks/stack_two_cubes/task.toml`

```toml
[task]
name = "stack_two_cubes"
instruction = "Stack the red cube on the blue cube"
default_variant = "teleop"

[task.variants]
teleop = "env_cfg:apply_teleop"
generate = "env_cfg:apply_generate"

[task.objects.red_cube]
size = [0.02, 0.02, 0.02]
mass = 0.008

[task.objects.blue_cube]
size = [0.02, 0.02, 0.02]
mass = 0.008

[task.roles]
target = "red_cube"
base = "blue_cube"

[task.start]
table_z_m = 0.0
min_separation_m = 0.06
clearance_m = 0.01
reachable = ["@target", "@base"]

[task.start.place.red_cube]
yaw_deg = [0.0, 90.0]

[task.start.place.red_cube.region]
xy_min = [-0.25, -0.40]
xy_max = [0.25, -0.18]

[task.start.place.blue_cube]
yaw_deg = [0.0, 90.0]

[task.start.place.blue_cube.region]
xy_min = [-0.25, -0.40]
xy_max = [0.25, -0.18]

[task.stages]
order = ["reached", "grasped", "lifted", "over_base", "stacked", "success"]

[task.stages.hold_until]
reached = "grasped"
grasped = "stacked"
lifted = "stacked"

[task.checks.reached]
check = "ee_near"
object = "@target"
tol_m = 0.02

[task.checks.holding]
check = "held"
object = "@target"

[task.checks.grasped]
check = "all"
of = ["holding"]

[task.checks.raised]
check = "object_lifted"
object = "@target"
min_lift_m = 0.01

[task.checks.lifted]
check = "all"
of = ["holding", "raised"]

[task.checks.above_base]
check = "ee_near"
object = "@base"
offset_m = [0.0, 0.0, 0.08]
tol_m = 0.03

[task.checks.over_base]
check = "all"
of = ["holding", "above_base"]

[task.checks.on_base]
check = "object_on_object"
object = "@target"
base = "@base"
xy_tol_m = 0.008

[task.checks.released]
check = "held"
object = "@target"
negate = true

[task.checks.stacked]
check = "all"
of = ["on_base", "released"]

[task.checks.ee_clear]
check = "ee_near"
object = "@target"
tol_m = 0.04
negate = true

[task.checks.success]
check = "all"
of = ["stacked", "ee_clear"]

[task.failures]
rules = [{ name = "stacked_not_confirmed", if = ["stacked"] }, { name = "never_reached", unless = ["reached"] }, { name = "missed_grasp", unless = ["grasped"] }, { name = "timeout_holding", if = ["holding"] }, { name = "dropped_before_base", unless = ["over_base"] }, { name = "fell_off_base" }]

[task.expert]
max_steps = 600
steps = [{ skill = "move_joint", q = "home" }, { skill = "set_gripper", gap_m = "open" }, { skill = "approach", target = "@target", offset_m = [0, 0, 0.06], stage = "reached" }, { skill = "grasp", target = "@target", stage = "grasped" }, { skill = "lift", height_m = 0.08, stage = "lifted" }, { skill = "transport", target = "@base", height_m = 0.06, stage = "over_base" }, { skill = "place", target = "@base" }, { skill = "release", stage = "stacked" }, { skill = "retreat", dz_m = 0.08, stage = "success" }]

[task.perturbations]
failure = [{ type = "grasp_offset", weight = 2, xy_m = [0.008, 0.02] }, { type = "early_release", stages = ["lifted"], delay_steps = [5, 40] }, { type = "place_offset", xy_m = [0.02, 0.04] }, { type = "object_drop", stages = ["lifted", "over_base"], xy_jitter_m = [0.0, 0.02] }]
recovery = [{ type = "grasp_offset", xy_m = [0.008, 0.02] }, { type = "object_shift", stages = ["reached"], xy_m = [0.02, 0.05], yaw_rad = [-0.5, 0.5] }, { type = "object_drop", stages = ["lifted"], xy_jitter_m = [0.0, 0.02] }]
```
