## Decisions (pinned by the tests)

- `PlannedEpisodeV2` is a frozen dataclass `(dst_index: int, src_index: int, draw: AppearanceDraw | None = None, copy_index: int | None = None)`.
- `plan_episodes_v2(sources, *, task_spec, cfg: DRConfig, exposure_range, robot_colors, include_originals)`:
  - `sources` are v2 sidecar dicts in the order given; any `legacy_v1` source or one without fingerprints raises `ValueError` (v1 datasets keep using `plan_episodes`).
  - Output: the originals first when `include_originals` (`draw=None`, `copy_index=None`, same order), then for each source `cfg.copies` copies with `copy_index` 0..copies−1. `dst_index` runs 0..len−1.
  - Each copy's draw is exactly `draw_appearance(parent, task_spec=task_spec, terms=cfg.terms, exposure_range=exposure_range, robot_colors=robot_colors, recolor=cfg.recolor, dr_seed=cfg.seed, copy_index=c, taken={parent appearance_fp} ∪ {appearance_fp of earlier copies of the same parent})`. Never mutate the inputs.
- `robot_color_names()` returns the keys of `ROBOT_COLORS` in `src/sim/envs/mdp/resets.py`, in order, read with `ast` (that module imports Isaac). The real run uses the same helper, so a dry run shows the draws the real run makes.
- `exposure_range(task_spec)` = `tuple(task_spec.raw["dr"]["room_light_exposure_range"])` as floats, default `(-3.0, 1.0)`.
- `sidecar_v2(planned, parent, *, source_repo_id)`: an original is a deep copy of the parent with `episode_index = dst_index`; a copy is `dr_copy_sidecar(parent, planned.draw, episode_index=dst_index, source_repo_id=source_repo_id)`. Validate with `validate_sidecar` before returning.
- `build_manifest_v2(plan, args, git_commit)` = `{"git_commit", "args", "episodes": [{"dst_index", "src_index", "copy_index", "draw": {"colors", "instruction", "light_exposure", "robot_color", "seed", "appearance_fp"} or null}], "counts": {"total", "originals", "copies"}}`; JSON-serialisable.
- `print_plan_v2(plan)` prints one JSON object per planned episode with keys `dst`, `src`, `copy`, `robot_color`, `light`, `instruction` (null for originals), then `"<n> episodes: <m> originals, <k> copies"`.
- `dr_replay`:
  - v2 path when `<src_root>/task_meta/` exists; otherwise today's v1 path, unchanged.
  - New arguments `--copies` (int, default 2) and `--no_recolor`. `--dr` terms are parsed as today (light, robot_color).
  - The v2 path reads the sources with `list_sidecars` / `read_sidecar` (minus `--exclude_episodes`; an unknown excluded index raises `ValueError`), requires one task per source dataset, loads its spec with `load_task_spec`, and plans with `DRConfig(copies, terms, recolor=not --no_recolor, seed=--seed)`, `exposure_range(spec)` and `robot_color_names()`. `--limit N` keeps the first N planned episodes.
  - `--dry_run` prints the plan with `print_plan_v2` and returns without creating the destination and without importing Isaac, LeRobot or gymnasium (the tests block those imports).
  - Real run: render each planned episode from its source frames (actions and states unchanged, poses of every object from the source sidecar), write the frame with the copy's instruction as `task` and the label columns copied from the source, save, then write `sidecar_v2(...)`; finally write `meta/dr_replay_manifest.json` with `build_manifest_v2`. The destination is a `LeRobotRecorder(extra_features=LABEL_FEATURES)` dataset.
- `load_source(root, repo_id, exclude, dataset=None, *, task="pick_place_cube", arm=None, scene=None)`:
  - reads each episode's sidecar with `load_episode(root, index, task=task, arm=arm, scene=scene)` (v2 first, v1 mapped);
  - `SourceEpisode` gains `objects` ({name: (N, 7) float64 `x y z qw qx qy qz`} for the sidecar's objects), `colors` ({name: colour}), `roles` and `meta` (the v2 sidecar dict); all four default to `None` so existing constructors keep working;
  - `poses_base` = the target role object's poses, `cube_size` = its `size_m` as a tuple; for v1 sources both are identical to today's values;
  - `SourceEpisode.task` stays the episode's task text from the dataset (do not shadow it with the `task` argument).
- `SceneReplayer.pose_frame(state_raw, poses_by_name)` poses every named object (disk order 7-vectors) and the joints; `apply` recolours objects from `draw.colors` via the palette; v1 calls keep working.
- `make_env` disables every event term whose function is `park_object` or a task spawn event (so the replay places all objects itself).

## Notes

- Tasks whose instruction templates use `{goal.*}` cannot be re-instructed (the sidecar has no goal); WP5 raises `GenerationError` for them, and no v4 task uses such placeholders.
- Container check after this lands: replay a generated dataset with `--copies 2`, audit the result against the source, and compare a no-DR copy's frames with the source render.
