Hardware configuration

Set up your arms, cameras and calibration paths. Download an environment file when you’re ready.

01

Arm connections

Identify the leader and follower using their serial ports and calibration IDs.

TELEOP_PORT

Prefer a stable /dev/serial/by-id/ path when available.

TELEOP_ID

Use the ID saved during leader calibration.

ROBOT_PORT

Serial device connected to the follower arm.

ROBOT_ID

Use the ID saved during follower calibration.

02

Camera inputs

Choose the wrist and room cameras, then set their capture format.

CAMERA_GRIPPER

Optional. Device index or /dev/v4l/by-id/ path.

CAMERA_EXTERNAL

Optional. Device index or /dev/v4l/by-path/ path.

CAMERA_WIDTH

Capture width in pixels.

CAMERA_HEIGHT

Capture height in pixels.

CAMERA_FOURCC

Four characters, e.g. YUYV or MJPG. Leave blank for backend default.

CONTROL_FPS

Recorder control rate in frames per second.

03

Calibration & paths

Set calibration locations and optional scene and model folders.

LEROBOT_CALIB

Calibration folder relative to your home directory.

HF_LEROBOT_CALIBRATION

$HOME is expanded when you source the downloaded file.

ROOM_USD_PATH

Optional. Leave blank to use the packaged room.

MODELS_DIR

Optional. Folder used by host evaluation scripts.
